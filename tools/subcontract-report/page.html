How the monthly loop works

Each month
  • The report has one row per service, supplier and contract rate, with qty, rate and amount for each month, plus Opening and Pending blocks.
  • SAP's subtotal rows are dropped, and lines split across several WBS elements are counted once.
  • With last month's report loaded, a Changes sheet lists new, changed, newly approved and removed certificate lines.
  • CSI, MNL and Cost Element Code come from the shared coding, which you can edit here after you build a report.
